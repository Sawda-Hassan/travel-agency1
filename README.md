# 🌍 Travel Agency Website

A **MERN stack travel agency application** that allows users to explore destinations, book trips, and manage their travel plans.  
The platform provides an intuitive frontend with a secure backend API, offering a smooth user experience.

🌐 **Live Demo:** [Travel Agency Website](https://travel-agency1-2ltb.vercel.app/)

---

## ✨ Features
- 🗺️ Browse travel destinations with images & details  
- 🔎 Search and filter trips  
- 🛒 Book and manage trips (CRUD functionality)  
- 👤 User authentication (signup/login)  
- 📱 Responsive design for all devices  
- ⚡ Fast API with MongoDB integration  

---

## 🛠️ Tech Stack
**Frontend:**
- React.js
- CSS / Tailwind / Styled Components (depending on your build)
- Axios for API calls

**Backend:**
